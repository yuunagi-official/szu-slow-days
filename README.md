# 深大出走

面向深圳大学粤海校区学生的日常出游助手，以慢慢散步、欣赏景色、放空和享受生活为主。按日常休闲、半天、全天筛选 95 项区域与玩法，包含原有 70 项及本轮新增 25 项；10 条慢跑完整保留。提供预算、交通、收藏及活动日期提示。

本目录是可直接发布到 GitHub Pages 的静态网站。发布目录为仓库根目录，入口是 `index.html`；不需要构建或业务 API。资源与数据均使用相对路径，适用于 `/szu-slow-days/` 项目子路径。

## 隐私

收藏、筛选偏好、熟悉地点与体验记录只保存在访客当前浏览器的 `localStorage`，不会发送到业务服务器。网站没有登录、统计或追踪脚本。导航、报名及来源链接由访客主动点击，打开对应外部服务。

## 数据与图片授权

区域和玩法分别维护于 `data/areas.json` 与 `data/experiences.json`。交通与费用是编辑估算；开放时间、校园权限及活动名额以当日官方信息为准。资料核验日期保留在每条内容中。

实景照片的作者、许可、原图及许可链接见 [data/photos.json](data/photos.json)，并在网页的照片授权说明及详情中展示。相关照片继续遵循各自原许可；已标注缩放、压缩与版式裁切。不得将图片统一视为网站作者原创或无版权图片。

原 Sites 项目另行保留，本目录不包含账号凭据、部署令牌或运行时秘密。

## 手机与路线资料

手机页面提供底部导航、可展开的补充筛选，以及适配安全区的布局。地点/绿道全称和玩法标题分别保存为 officialName、playTitle；原 ID 保持，已有收藏兼容。慢跑数据用 activity=run 与 runInfo 记录建议累计公里数、起终点、折返位置、路面、遮阴、人车交汇和资料边界；公里数除注明的官方路段外不代表 GPS 实测轨迹。

本轮对 21 项名称另核官方或运营方资料；慢跑 10 项保留 42 个不同来源链接。未实地跑线，旧实跑记录与官方建设资料的日期、适用范围在详情里说明。

## 随机推荐与高德地图

每次打开页面重新随机抽取三处；候选足够时避开上一批。默认搭配自然与生活，指定主题或慢跑时在该条件内随机；收藏、排序和普通重渲染不会重抽。上一批 ID 仅保存在浏览器本地，以减少连续重复。

卡片只显示正式名称、一句引入和三项估算，直接提供导航。详细路况、参与条件及来源按需展开。手机主按钮使用高德官方原生协议：iPhone 以入口名称打开公交路线规划，Android 打开地点搜索；电脑及详情里的“用网页版”使用 HTTPS。原生链接须访客点击并已安装高德，App 唤起和名称定位仍受设备、浏览器及高德版本影响，本站未作真机验收。[iOS 官方文档](https://lbs.amap.com/api/amap-mobile/guide/ios/route) · [Android 官方文档](https://lbs.amap.com/api/amap-mobile/guide/android/search)

现有 69 张授权实景照片，本轮补充中山公园、南山区图书馆、春茧、海上世界文化艺术中心、深圳湾文化广场和大芬油画村照片。48 项有对应或明确标注片区参考的照片，47 项仍用文字封面；无法确认点位的照片不作替代。

## 2026-10-18 近校选线

新增25项中，18项按单程上限45分钟估算，补学府路、南光路、超市、公共阅读空间及短段园路；大芬油画村另列较远半天路线，往返约2.5–3.5小时。所有交通从粤海校门至入口，含候车、换乘与末段步行，不代表实时导航；餐饮路线含一份简单餐食，其他路线不自动包含可选消费。
