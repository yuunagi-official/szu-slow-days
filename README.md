# 深大出走

从深圳大学粤海校区出发的散步、慢跑与生活探索助手。95项区域与玩法，含10条慢跑；地点资料和69张授权照片分别维护于data目录。

本目录可直接发布到GitHub Pages，入口index.html。不需要构建、账号或业务API，全部资源使用相对路径，适用于项目子目录/szu-slow-days/。

## 使用流程

- **发现**：打开即可看随机三处，也可一键选附近、海边、绿地、逛吃、文化或慢跑。推荐只考虑今天可安排的项目，每组地点不同；进入页面或换组时重新抽取，普通收藏、切页、筛选不重抽。
- **探索**：一份统一结果列表。直接搜索地点或玩法，按主题浏览，可选交通、预算、日期与参与条件。没有日常/半天/全天分档入口。筛选面板先改草稿，确认才影响结果；关闭、Escape或浏览器返回均放弃未确认的改动。
- **想去**：独立显示全部收藏，最近收藏排前，不受探索的查询、分类、日期或筛选影响。取消收藏后6秒内可撤销。

三个入口切换实际页面，不再只是滚动到同页不同区块。探索保留搜索、分类、排序、已加载数量；切页、详情返回及浏览器前进/后退恢复对应位置。顶部搜索只影响探索；清除搜索只清关键词，重置本次查找才清全部条件。“看看全部95处”明确重置，普通探索导航保留当前查找。

卡片可直接进入详情，或收藏、导航。详情只呈现正式名称、简短引入、时间费用、入口和两三个停留点；路况、开放、资料和照片来源按需展开。手机底部固定导航和详情操作适配安全区。

## 数据、隐私与兼容

区域和玩法仍分别保存在data/areas.json与data/experiences.json。本轮交互改版未修改95项内容、原ID、开放条件、活动期限和图片元数据；历史band字段留在数据中供兼容，界面和筛选不再依赖它。

原localStorage键szu-slow-days:v1和saved/familiar/tried记录保持。新版交通、预算与参与偏好保存在explorePreferences；旧时间和主题筛选不自动套用。关键词、分类和页面上下文使用当前会话/浏览器历史，收藏只存在访客本机。没有登录、统计或追踪脚本。

交通从粤海校门到入口，含候车、换乘和步行。预算按每人往返公共交通＋必要门票/主要体验，逛吃含一份简单餐食，额外购物消费另计。过滤按区间上限；不能把编辑估算当实时导航。

已结束活动退出发现推荐，仍可在探索和想去查看；启用“隐藏当日不开放、已结束及待核实项目”后才从探索结果排除。预约/名额、校园权限、双周闭馆与临时管制均以原数据说明和当天官方公告为准。

照片作者、许可、原图及编辑范围见data/photos.json，并在每条指南与说明页展示。48项有对应或明确标注片区参考图，47项仍用诚实文字封面。原照片许可分别适用，不能视为网站作者原创。

## 高德导航

iPhone使用官方iosamap://path，以入口名称打开公交规划；Android使用androidamap://poi地点搜索；电脑与详情的备用入口使用HTTPS。原生跳转需要设备安装高德并允许浏览器唤起，不保证所有名称定位准确，未作iPhone真机验收。
