# 深大出走

从深圳大学粤海校区出发的散步、慢跑与生活探索助手。100项区域与玩法，含10条慢跑；地点资料和72张授权照片分别维护于data目录。

本目录可直接发布到GitHub Pages，入口index.html。不需要构建，访客无须账号。路线与照片使用本地相对路径；预报通过公开免费天气API读取，适用于项目子目录/szu-slow-days/。

## 使用流程

- **发现**：打开即可看随机三处，也可一键选附近、海边、绿地、逛吃、晚霞或慢跑。推荐只考虑今天可安排且商业程度较低的项目，每组地点不同；进入页面或换组时重新抽取，普通收藏、切页、筛选不重抽。
- **探索**：一份统一结果列表。直接搜索地点或玩法，按主题浏览，可选交通、预算、日期与参与条件。没有日常/半天/全天分档入口。筛选面板先改草稿，确认才影响结果；关闭、Escape或浏览器返回均放弃未确认的改动。
- **想去**：独立显示全部收藏，最近收藏排前，不受探索的查询、分类、日期或筛选影响。取消收藏后6秒内可撤销；详情弹层内的提示和撤销按钮也可直接操作。

三个入口切换实际页面。探索保留搜索、分类、排序、已加载数量；切页、详情返回及浏览器前进/后退恢复对应位置。顶部搜索只影响探索；清除搜索只清关键词。“探索100项路线”重置查询和时间条件，保留商业偏好；普通探索导航保留当前查找。“恢复默认”会重新启用避开强商业。

卡片可直接进入详情，或收藏、导航。详情呈现正式名称、简短引入、时间费用、入口和两三个停留点，停留点附简短玩法；路况、开放、资料和照片来源按需展开。路线资料加载失败或超时后可重新加载，本机收藏保留。手机底部固定导航和详情操作适配安全区。

界面在支持backdrop-filter的浏览器上，为顶部工具、底部浮动导航和弹层操作加入半透明、模糊与高光的玻璃效果。内容卡片保留实底；不支持该能力时使用实色背景。“关于”内可关闭玻璃界面，选择单独保存在szu-glass:v1；系统开启减少透明度时也回退为实底，减少动态效果和高对比度设置另有适配。这是CSS渐进增强，不是iOS原生界面实现。

## 晚霞与少商业

首页先呈现搜索、主题入口和路线推荐，天气以一条紧凑摘要辅助选择，点击“看预报”滚动到推荐之后的完整面板，也可返回推荐。面板提供未来三天的参考评分，可切换朝霞及粤海/深圳湾、前海石、西湾、立新湖、石岩湖五个公共片区；云量、AOD、能见度和降雨概率按需展开。

晚霞预报的路线按钮把所选日期和片区带到探索，只显示对应片区已整理的晚霞条目，可移除条件查看其他去处；探索中的预报入口可回看天气。早场跳转所选日期的海边分类，并提醒另行确认朝向、开园和首班车，不把晚霞点自动当作朝霞点。

天气由Open-Meteo免费非商业API提供（无需密钥），选择NOAA GFS模型；AOD使用Open-Meteo转发的CAMS全球预报。前端直接访问，无新增后端、API密钥或手机定位权限。请求只包含公共片区坐标；接口响应和跨域检查记录见本轮天气报告。免费条件和配额见[Open-Meteo条款](https://open-meteo.com/en/terms)，不能理解为无限流量或商业使用许可。

评分是0–100经验指数，不是火烧云发生概率，也不是FollowSun原算法。中高云、低云、太阳方向约60km处的参考格点、能见度、AOD与降雨共同参与。权重未以深圳实拍校准；网格云量无法反映每一片云或云厚。数据缺失时标明受限，关键云量不足时不给分，雷雨或强降雨另作提示。页面保留Open-Meteo/CAMS与CC BY4.0署名。

天气仍缓存在独立localStorage键szu-sky:v1，缓存内容已升级为schema v2，旧版本缓存会重取；校验片区、三天覆盖、天文时段、缺项与评分数据。一小时内复用，一至六小时标旧数据，超过六小时或日期覆盖失效就退出评分。后台标签不主动刷新，回到页面及前台定时检查会更新过旧预报；切换片区取消旧请求，跨北京时间午夜重取新三天。网络失败提供重试，路线浏览不受影响。显示数据获取时间，不冒充模式起报时间。

天文时段用本地SunCalc1.9.0计算，保留BSD2-Clause许可（assets/vendor/suncalc-LICENSE.txt）。北京时间固定UTC+8，金色采用太阳高度−4°至6°，蓝调采用−6°至−4°；楼宇、山体和天气会改变观感。

首页和探索都有“看晚霞”入口，仅收录六处已整理的停留点。区分前海石、西湾的夕照与湖岸、日出剧场的天色余晖，不把所有海边自动当日落点。详情补充具体位置、返程与晚霞资料日期；按当季日落时间提前30–45分钟到，天气不作保证。

探索默认启用“避开强商业”，略过四家商场卖场超市与南头古城；可移除条件或在筛选中关闭，旧收藏和分享直达始终可用。居民市场、学府路、南光路及自主消费的小店继续保留。首页始终不随机抽取强商业项目。

curation记录low/mixed/high及编辑理由；sunset独立保存类型、具体位置、返程、核对日期，可追溯本条来源。商业程度是玩法取向的编辑判断，公共空间并不代表无人或绝对安静。

## 数据、隐私与兼容

区域和玩法分别保存在data/areas.json与data/experiences.json。本轮保留全部100个ID、10条慢跑和六处晚霞资料；晚霞条目另有片区字段用于预报联动。全部条目保留商业取向；前海公园芦趣湖开放范围待核实，不进入随机推荐。历史band字段留在数据中兼容，界面和筛选不依赖它。

原localStorage键szu-slow-days:v1和saved/familiar/tried记录保持。新版交通、预算与参与偏好保存在explorePreferences；旧时间和主题筛选不自动套用。关键词、分类和页面上下文使用当前会话/浏览器历史，收藏只存在访客本机。没有登录、统计或追踪脚本。

交通从粤海校门到入口，含候车、换乘和步行。预算按每人往返公共交通＋必要门票/主要体验，逛吃含一份简单餐食，额外购物消费另计。过滤按区间上限；不能把编辑估算当实时导航。

已结束活动退出发现推荐，仍可在探索和想去查看；定时活动若未公布结束时间，开场后标为“已开场 · 入场看主办方安排”，不继续作为可安排推荐。探索的参与条件筛选可排除当日不开放、已结束及待核实项目；需预约项目仍须先取得有效凭证，筛选不代表实时有余量。预约/名额、校园权限、双周闭馆与临时管制均以原数据说明和当天官方公告为准。

照片作者、许可、原图及编辑范围见data/photos.json，并在每条指南与说明页展示。52项有对应或明确标注片区参考图，48项仍用诚实文字封面。72张原图保留，另生成320/640像素共144张渐进式JPEG缩略图；列表通过srcset选择缩略图，详情主图继续用原图。缩略图保持画面比例，不增加新的实景覆盖。历史影像注明年份，原照片许可分别适用，不能视为网站作者原创。

## 高德导航

iPhone使用官方iosamap://path，以入口名称打开公交规划；Android使用androidamap://poi地点搜索；电脑与详情的备用入口使用HTTPS。原生跳转需要设备安装高德并允许浏览器唤起，不保证所有名称定位准确，未作iPhone真机验收。

尚待确认馆区或上车点的活动先提供官方报名/集合点确认链接，不把说明文字当作已确认的导航入口。科技公园/云之园、紫荆园/桂湾这类二选一组合，在详情提供备选地点的独立地图入口。
